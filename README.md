## 🏗️ Projet principal — Homelab Proxmox

Infrastructure auto-hébergée sur serveur physique sous **Proxmox VE**.

| Conteneur | Rôle | Technologies |
|-----------|------|--------------|
| **CT100** — Média & Cloud | Streaming, stockage, téléchargement | Plex, Jellyfin, Nextcloud, Vaultwarden, *arr stack |
| **CT101** — Passerelle | Reverse proxy, accès distant, tunnel | Nginx PM, Cloudflare Tunnel, Guacamole |
| **CT102/103** — Web | Sites WordPress | WordPress, MariaDB, PHP 8.3, Redis |
| **CT104** — Bureau Linux | Lab graphique accessible via RDP/VNC | XRDP, noVNC, Fail2ban |
| **CT105** — DNS | Filtrage DNS réseau local | Pi-hole, DNSCrypt-proxy |
| **CT500** — Cybersec | OSINT & reconnaissance | SpiderFoot, Maigret, Holehe, theHarvester, Recon-ng |

> Tout le trafic externe passe par **Cloudflare Tunnel** — aucun port ouvert sur internet.
